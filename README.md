# OSAFUNE KAJIBITO STAY（仮称）— 2泊3日 鍛冶人体験 販売サイト

kurabitostay.com の構成・トーン（白地×墨色、明朝体、縦書き見出し＋英字サブタイトル、全画面写真、横スクロールの募集カード、右下固定の BOOKING ボタン、ドロワーメニュー）を参照して作成。

## ファイル
| ファイル | 内容 |
|---|---|
| index.html | トップ（ヒーロー／コンセプト／鍛冶人体験＋募集カード／三日間の流れ／刀剣文化／施設案内／お知らせ／交通案内／周辺のみどころ） |
| plan.html | 2泊3日プラン詳細（期日・料金・含まれるもの・特典・工程・スケジュール・宿泊・参加条件・申込フォーム） |
