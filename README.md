## 写真
`images/` の写真は、Wikimedia Commons／Flickr でクリエイティブ・コモンズ（CC0・CC BY・CC BY-SA）として公開されている写真を、条件に従って使用しています（縮小・トリミングのみ）。作者とライセンスの一覧は [credits.html](credits.html) に掲載済みで、全ページのフッターからリンクしています。**CC BY／BY-SA の写真はクレジット表記が利用条件なので、写真を使う限り credits.html は消さないこと。**

宿・料理・鍛冶場の写真は**イメージ（他所の写真）**です。実際の施設・料理として誤認させると景品表示法上の問題になり得るため、販売開始までに自前の写真へ差し替えてください。同じファイル名で `images/` に上書きすれば反映されます（差し替えた写真は credits.html から行を削除）。

## 公開前に差し替えが必要な仮置き情報
- ブランド名「OSAFUNE KAJIBITO STAY」（仮称）
- 料金（調整中と表示）、開催日程（年3〜4回・1回最大4名。3人の刀匠の鍛冶場に1〜2名ずつ分かれる）
- 刀匠名（公開の可否を本人に確認してから掲載）
- 刀匠名・宿の名称と部屋構成・集合時間などスケジュール詳細
- 旅行業登録番号（フッター）※宿泊＋体験のパッケージ販売には旅行業登録または登録事業者との提携が必要
- 長船駅からの「無料送迎」：送迎費を旅行代金に含めず、本当に無償で行うこと（有償扱いになると、自家用車での送迎は道路運送法に抵触。主催の旅行会社・バス会社の車両で行うのが確実）
- メールアドレス（info@example.com）、SNS リンク、EN ページ
- 申込フォームの送信先（現在は送信せず完了メッセージのみ表示。Googleフォーム／Formspree／予約システム等に接続）
- お知らせ記事、旅行条件書・プライバシーポリシーのページ
